# Explore Directory (Premium Profile Directory)

A curated premium profile directory web application built with Next.js, React 19, Tailwind CSS, and Supabase integration.

## Features

- **Profile Directory**: Explore and filter profiles and portfolios.
- **Modern UI**: Built with Tailwind CSS and Radix/shadcn-inspired components.
- **Supabase Integration**: Optional cloud database integration with fallback to demo profiles.
- **Smooth Scrolling & Responsive**: Optimized for desktop and mobile screens.

## Getting Started

### 1. Install Dependencies

```bash
npm install
# or
pnpm install
```

### 2. Environment Variables (Optional)

Copy `.env.example` to `.env.local` if using Supabase:

```bash
cp .env.example .env.local
```

### 3. Run Development Server

```bash
npm run dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
